GUIDE — E-mails Supabase Auth avec Maileroo via Edge Function
==============================================================

Le site utilise déjà Supabase Auth pour demander et appliquer la
réinitialisation du mot de passe. La fonction Edge `send-auth-email` remplace
uniquement l’envoi des e-mails : le lien de récupération et les jetons restent
générés et validés par Supabase.

PRÉPARER MAILEROO
-----------------

1. Dans https://app.maileroo.com/, ajouter le domaine d’envoi.
2. Ajouter dans le DNS les enregistrements SPF, DKIM et DMARC indiqués par
   Maileroo, puis attendre que le domaine soit vérifié.
3. Ouvrir le domaine > « Sending Keys » > « New Key » et créer une clé nommée
   par exemple `Supabase production`.
4. Noter l’adresse d’expéditeur choisie, par exemple `no-reply@votredomaine`.
5. Désactiver le suivi des clics et ouvertures pour ce domaine / ces e-mails :
   un lien d’authentification ne doit pas être modifié par un outil de tracking.

INSTALLER LA FONCTION DANS SUPABASE
-----------------------------------

1. Dans Supabase : Edge Functions > « Deploy a new function » > « Via Editor ».
2. Nommer la fonction `send-auth-email`.
3. Copier le contenu de `supabase/functions/send-auth-email/index.ts` dans
   l’éditeur, puis cliquer sur Deploy.
4. Dans Edge Functions > Secrets, créer ces secrets (sans les ajouter au code) :

   - `MAILEROO_SENDING_KEY` : la Sending Key Maileroo créée à l’étape 3.
   - `MAILEROO_SENDER_EMAIL` : l’adresse validée, par exemple
     `no-reply@votredomaine`.
   - `MAILEROO_SENDER_NAME` : `Kymia Clinical Sim`.
   - `SEND_EMAIL_HOOK_SECRET` : le secret généré à l’étape suivante, au format
     complet `v1,whsec_...`.

ACTIVER LE HOOK D’AUTHENTIFICATION
----------------------------------

1. Dans Supabase : Authentication > Hooks.
2. Créer un hook « Send Email » de type HTTPS.
3. Utiliser l’URL de la fonction :
   `https://xkbtyljhwxbepmptsjed.supabase.co/functions/v1/send-auth-email`
4. Cliquer sur « Generate Secret », copier le secret dans
   `SEND_EMAIL_HOOK_SECRET` (Edge Functions > Secrets), puis enregistrer le hook.
5. Vérifier que le fournisseur e-mail de Supabase reste activé : avec le hook,
   l’e-mail est envoyé par la fonction et non par SMTP.

CONFIGURATION DES URLS
----------------------

Dans Authentication > URL Configuration :

- Site URL : l’adresse publique principale du site.
- Redirect URLs : ajouter `https://votre-domaine/reset-password`.
- Pour le développement local, ajouter aussi
  `http://localhost:5173/reset-password`.

TEST
----

1. Ouvrir la page de connexion puis « Mot de passe oublié ? ».
2. Demander le lien pour un compte de test.
3. Vérifier dans les logs de la fonction et dans Maileroo que le message est
   accepté.
4. Ouvrir le lien et choisir un nouveau mot de passe.
5. Se reconnecter avec ce mot de passe.

SÉCURITÉ
--------

- Ne jamais mettre de Sending Key Maileroo, de secret de hook ou de mot de passe
  SMTP dans `.env` public, le frontend ou Git.
- La fonction vérifie la signature Standard Webhooks de Supabase avant tout
  envoi ; elle accepte donc seulement les demandes émises par Supabase Auth.
- Le formulaire garde une réponse neutre pour ne pas révéler si une adresse
  e-mail possède un compte.
